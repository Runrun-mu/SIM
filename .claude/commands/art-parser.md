# /art-parser — 美术资源解析与索引工具

你是一个美术资源解析助手。当用户在 `rawasset/` 中添加新的资源包时，执行以下完整流程来建立三层索引体系。

## 三层索引体系

```
agent.md                          # 第1层: 顶层索引 (资源包一览表)
└── rawasset/
    ├── 资源包A/
    │   └── art-index.md          # 第2层: 包级索引 (目录结构 + 格式说明)
    │       └── 每个资源的文字描述    # 第3层: 资源级描述 (内联在 art-index.md 中)
    └── 资源包B/
        └── art-index.md
```

## 步骤 1: 扫描 rawasset 目录

```
使用 Bash ls rawasset/ 获取所有资源包目录
对比 agent.md 中已有的美术资源索引，找出：
- 新增的资源包（需要创建索引）
- 已有的资源包（检查是否有变化）
```

## 步骤 2: 对每个新资源包，分析内容

### 2.1 识别资源包类型

读取资源包根目录内容，判断类型：
- **角色包**: 包含人物模型 (检查文件名含 Male/Female/Character 等)
- **场景包**: 包含方块/地形/建筑 (检查文件名含 block/terrain/building 等)
- **道具包**: 包含物品/装备 (检查文件名含 item/weapon/tool 等)
- **动画包**: 包含动画文件 (检查 .anim/.fbx 等)
- **材质包**: 包含贴图/材质 (检查 .png/.jpg/.mat 等)

### 2.2 读取预览图

如果资源包包含预览图 (contents.png, sample.png, Preview.png 等)：
- 使用 Read 工具查看图片
- 从图片中识别资源的视觉特征（颜色、风格、形状）
- 将视觉信息写入文字描述

### 2.3 读取许可证

如果有 License.txt：
- 提取许可证类型 (CC0, MIT, 等)
- 提取作者信息

### 2.4 列举所有资源

扫描可用格式 (优先级: gltf > fbx > obj > blend):
- 列出所有模型文件名
- 根据文件名 + 预览图推断每个资源的文字描述

## 步骤 3: 为资源包创建 art-index.md

在资源包根目录创建 `art-index.md`，格式如下：

```markdown
# {资源包名称} — 美术资源索引

> {一句话描述资源包内容和风格}

## 基本信息

| 属性 | 值 |
|------|-----|
| 作者 | {作者} |
| 许可证 | {许可证类型} |
| 风格 | {低多边形/写实/卡通/像素 等} |
| 类型 | {角色/场景/道具/动画/材质} |
| 数量 | {资源数量} |
| 可用格式 | {gltf, fbx, obj 等} |
| 推荐格式 | gltf (Web 友好, R3F 直接加载) |

## 目录结构

{展示资源包的文件夹结构}

## 资源清单

### {分类1}
| 文件名 | 描述 | 标签 |
|--------|------|------|
| resource_name | 一句话文字描述（颜色/形状/用途） | #标签1 #标签2 |

### {分类2}
...
```

**描述规则**:
- 每个资源用一句中文描述，包含：主体外观 + 颜色 + 关键特征
- 例如：`grass` → "绿色草地方块，顶部有波浪状草纹"
- 例如：`Casual_Male` → "休闲装男性，短袖T恤+牛仔裤，深色短发"
- 标签用于快速搜索: `#自然 #建筑 #角色 #武器` 等

## 步骤 4: 更新 agent.md 顶层索引

在 `agent.md` 的美术资源区域更新索引表：

```markdown
## 美术资源

| 资源包 | 类型 | 风格 | 数量 | 许可证 | 索引 |
|--------|------|------|------|--------|------|
| {包名} | {类型} | {风格} | {数量} | {许可证} | [详情](rawasset/{目录名}/art-index.md) |
```
